# Atividade-laboratorio-web
Este site foi desenvolvido como parte de um estudo prático de desenvolvimento web, com o objetivo de aplicar conceitos de HTML, Bootstrap e visualização de informações. O projeto reúne diferentes formas de apresentar dados, permitindo explorar tabelas, gráficos e mapas em uma única aplicação.
