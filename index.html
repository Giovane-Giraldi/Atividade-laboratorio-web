Bem-vindo ao Sistema da aula de Laboratório de Desenvolvimento Web

Todos os dados utilizados nesse site foi gerado de forma aleatória. Este projeto permite colocar em prática os conhecimentos adquiridos durante os estudos de desenvolvimento web, explorando diferentes recursos para organizar e apresentar informações de maneira clara e acessível.

Tabela de Alunos

A tabela apresenta os nomes dos alunos, suas notas, médias finais e situações acadêmicas.

Gráficos

A página de gráficos transforma os dados escolares em representações visuais. O gráfico de barras permite comparar as médias dos alunos, o gráfico de linhas apresenta a variação das notas por bimestre e o gráfico de pizza demonstra a quantidade de aprovados e reprovados.
